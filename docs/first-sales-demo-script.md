# Furneq First Sales Demo Script

## Goal

Show one clear promise:

- the client leaves a request in Telegram
- the request becomes a deal in CRM
- the manager and owner see the same operational card
- the workshop moves the order to measurement, estimate and deposit

## Best Audience

- owner of a furniture workshop
- sales manager
- operations lead

Do not start with developers or abstract automation talk.

## Demo Flow

### 1. Open the bot

Show:

- the client menu
- `Leave a request`
- `Check order status`
- `Confirm measurement`
- `Get estimate`
- `Contact manager`

Say:

> Your client stays in Telegram. They do not need another app or a long form.

### 2. Create a live request

Go through the short request flow in the bot:

- client name
- phone
- product type
- short note

Say:

> In a real workshop this is the fastest way to turn an inbound message into a clean deal.

### 3. Open CRM

Show:

- the new deal in `/leads`
- the deal card
- next step
- source
- comments

Say:

> The team does not lose the request in chats. It becomes an order card immediately.

### 4. Show the manager flow

Open:

- `/workboard`
- the same deal card

Highlight:

- follow-up
- measurement
- estimate queue
- payment focus

Say:

> The manager sees what to do next, and the owner sees where money is stuck.

### 5. Show the operational card

Inside the deal card show:

- project files
- estimate
- production block
- installation block

Say:

> Sales, estimate, project files and workshop progress live in one card instead of separate chats and spreadsheets.

## Demo Close

Ask:

- How do you receive requests now?
- Where do you lose clients most often?
- Who controls measurements and deposits?

Then say:

> We can launch this as a pilot for one workshop, one bot and one team flow, and adapt the details around your real process.

## Pilot Offer

### What is included

- one Telegram bot
- one CRM workspace
- client request flow
- manager workboard
- deal cards
- measurements
- estimate and project files
- internal staff alerts

### What is not included in the pilot

- full accounting
- complex ERP features
- multi-branch rollout
- deep external integrations

## Main Selling Point

Do not sell it as "just CRM".

Sell it as:

> A Telegram-first operating system for a furniture workshop that helps capture requests, move them to measurement, push them to estimate and control the team in one place.
